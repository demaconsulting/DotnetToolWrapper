# Introduction

This document contains the build notes for this version of DotnetToolWrapper.

## Purpose

The build notes record what changed in this build of DotnetToolWrapper since the previous release, and the versions
of the tools used to build it. They are also the release notes of the GitHub release.

## Scope

The build notes cover:

- the version and commit of this build and of the previous release;
- the changes, fixed bugs, and dependency updates since the previous release, and the known issues;
- the versions of the .NET SDK and the tools used by each CI job.

## Generation Source

BuildMark generates the build report on every build from the Git history and the GitHub issues and pull requests.
VersionMark publishes the tool versions captured by each CI job.

## Audience

This document is intended for:

- package authors and users deciding whether to update to this version;
- maintainers and contributors tracking the changes between releases;
- quality assurance staff and auditors who need the build record of a release.
